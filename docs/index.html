Kashiwazaki SEO Link Card マニュアル

Kashiwazaki SEO Link Card は、URLをOGP情報付きのリッチなカード形式で表示するWordPressプラグインです。外部・内部リンクを自動判別し、サイト名・説明文・サムネイルを含むリンクカードを生成します。クリック解析機能により、リンクカードのクリック数をトラッキングし、ユーザーの行動を把握できます。

リンクをカード形式で表示することで、ユーザーのクリック率と回遊率を向上させることができます。本プラグインはOGP情報を自動取得してリッチなリンクカードを生成し、クリック解析機能でリンクの効果を測定します。

主な特徴

  • OGPベースのリンクカード - URLからOGP情報をスクレイピングし、タイトル・説明文・サムネイル画像を含むリッチなカードを自動生成します
  • 外部・内部リンクの自動判別 - リンク先が外部サイトか内部ページかを自動で判別し、バッジやスタイルを切り替えます
  • クリック解析機能 - 専用のカスタムテーブル（wp_kslc_analytics）にクリックデータを記録し、管理画面の解析ページで統計を確認できます
  • カラーテーマ・デザインカスタマイズ - カラーテーマ、サムネイル位置（左・右）、バッジ表示設定など、豊富なデザインオプションを提供します
  • REST API対応 - REST API（/wp-json/kslc/v1/）を通じたデータ取得が可能です
  • 軽量フロントエンド - フロントエンドのCSS（11KB）とアナリティクスJS（2KB）で、ページ速度への影響を最小限に抑えます

SEOとGEOへの効果

本プラグインは、検索エンジン最適化（SEO）と生成エンジン最適化（GEO）の両面で効果を発揮します。

  • ユーザーエンゲージメントの向上 - リッチプレビュー付きのリンクカードは、テキストリンクと比較してクリック率が高く、ユーザーのサイト内回遊を促進します
  • アウトバウンドリンクの価値分析 - クリック解析機能により、どの外部リンクがユーザーにとって価値があるかを把握し、リンク戦略の改善に活用できます
  • 内部リンクエクイティの最適化 - リンクカードによる適切なリンク表示は、内部リンクの導線を明確にし、リンクエクイティの流れを改善します
  • GEO対応 - リッチなリンクコンテキスト（タイトル・説明文・サムネイル）は、AIクローラーがコンテンツ間の関連性を理解する際の手がかりとなります。OGP情報に基づく構造化されたリンク表示により、AIはリンク先の内容をより正確に把握できます

技術仕様

  • データ保存: wp_options (kslc_*系)
  • カスタムテーブル: wp_kslc_analytics
  • 外部通信: wp_remote_get (OGPスクレイピング)
  • REST API: /wp-json/kslc/v1/
  • Cron: なし
  • メール: なし
